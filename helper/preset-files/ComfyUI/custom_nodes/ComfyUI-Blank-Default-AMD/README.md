# Blank Default Workflow (AMD)

ComfyUI opens its own default workflow (a ready-made image workflow) whenever there is no workflow to restore: on the first start, after the open tabs are closed, and from **Load Default**. With this extension that untitled workflow starts empty instead, so you begin from a clean canvas. Your saved and open workflows are not touched.

## Install

Easy Install adds it to `ComfyUI/custom_nodes` for you. By hand: copy the `ComfyUI-Blank-Default-AMD` folder into `ComfyUI/custom_nodes`, restart ComfyUI, then reload the browser. No requirements and no nodes.

To get ComfyUI's default workflow back, open **Settings**, search for **Blank Default**, and switch it off. Easy Install copies this folder back on every update, so use the setting rather than deleting the folder.
